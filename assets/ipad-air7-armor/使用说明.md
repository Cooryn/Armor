# iPad Air 7 11 寸红方装甲板

几何来自 `src/solver.cpp`：`armor_width_m = 0.135f`、`armor_height_m = 0.056f`。四个 PnP 角点是两根灯条中心线的上下端点。

- 两根红灯条中心线间距：135 mm。
- 每根红灯条长度：56 mm。
- 灯条宽度：10 mm，为本图的显示设置；代码没有规定灯条宽度。
- 图案总外宽：145 mm。不能用外边缘间距代替 135 mm 中心间距。
- 黑底、纯红色矩形灯条，无光晕；默认白色数字 3，可在页面关闭。

## 推荐：用显示页面

在 iPad Safari 打开在线页面。也可在电脑启动本目录的 HTTP 服务，让同一局域网中的 iPad 访问。直接在 iPad“文件”里预览 HTML 通常不会执行页面脚本。

建议 Safari 分享 → 添加到主屏幕，然后从主屏幕全屏打开。用实体尺量白色横线的两端刻线中心距离，以及竖线的两端刻线中心距离。分别填入实际毫米数，点击“按实测值校准”。复测应为横线 100 mm、竖线 50 mm，随后点击“开始显示”。开始显示后控件会自动隐藏；双击屏幕可回到设置。

页面使用实体像素密度换算，不把 CSS `mm` 当成屏幕真实毫米。图案不会为了适应窗口自动缩小。默认换算为 `264 / 25.4 / devicePixelRatio` CSS 像素/毫米，尺子校准分别修正水平与竖直方向。不同浏览器、分屏、显示缩放或页面缩放下，请重新复核校准。

## 直接用 PNG

Air 7（M3）11 寸官方参数为 2360 × 1640 像素、264 ppi：https://support.apple.com/zh-cn/122241 。

- `red-armor-air7-landscape.png`：2360 × 1640，横屏，数字 3。
- `red-armor-air7-portrait.png`：1640 × 2360，竖屏，数字 3。
- `red-armor-air7-plain-landscape.png`：横屏，无数字。
- `calibration-air7-landscape.png`：横屏，校准横线 100 mm、竖线 50 mm；不要拿校准图做检测。

保存到 iPad，按对应方向全屏显示、隐藏相册按钮、不裁切、不手动放大。先用校准图确认横线 100 mm、竖线 50 mm；如果有误差，改用可校准的页面。普通图片预览或聊天中的图片尺寸无法保证 1:1。

PNG 灯条中心间距约 1403.15 像素，长度约 582.05 像素。像素边缘存在约一个像素（0.096 mm）的量化范围；物理尺寸应以实体尺复核。SVG 保留连续几何与毫米标注，但浏览器直接预览 SVG 仍需校准。

## 检测时

全屏后用尺复核红灯条中心间距 135 mm、长度 56 mm。关闭原彩、夜览与自动亮度，固定亮度，并调整相机曝光，避免红色过曝泛白或反光影响端点定位。屏幕可作为平面视觉目标；与真实灯条的光照、发光与反射特性有区别。

修改代码尺寸后，用项目 Python 环境运行本目录 `generate.py`，即可重新生成图片、SVG 与显示页面。在线页面也需同步更新。
