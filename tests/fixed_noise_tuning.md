# 固定观测噪声调参记录

## 2026-10-12：当前四板联合模型

部署参数为 `R=diag(0.0016, 0.0004, 0.16, 0.0784)`，顺序为目标方位、目标俯仰、距离、板朝向；对应标准差为 0.04 rad、0.02 rad、0.40 m、0.28 rad。过程噪声维持 `q_pos=3, q_yaw=15, q_r=3e-4, q_dl=q_dh=3e-3`，关联门限不变。

使用当前 C++ 关联与联合更新实现，比较原部署参数 `diag(0.0016,0.0016,0.16,0.0576)` 与 319 组候选。数据仍为两段真实记录及八段合成轨迹，分别评估 50 ms、100 ms。各序列前 70% 排序，后 30% 参与保护筛选，因此后段不是独立测试集；真实记录没有外部真值。

最终选择两个提前量都通过筛选的 candidate_181。100 ms 排名第一的 candidate_184 将距离方差增至 0.3136，但部分合成场景退步，因此未部署。所选参数相对基线：

| 指标 | 50 ms 前段／后段 | 100 ms 前段／后段 |
| --- | --- | --- |
| 真实未来观测残差综合指标 | -2.19% / +0.47% | -1.94% / +0.71% |
| 合成中心及板位置真值误差综合指标 | -1.96% / -1.85% | -2.24% / -2.16% |
| 真实中心与角速度增量 RMS 综合指标 | -6.91% / -7.16% | -6.91% / -7.16% |
| 真实观测接受数量 | 不变 | 不变 |

综合指标是相对基线的各项比值平均，不是同单位的单个 RMSE；增量 RMS 包含真实运动，不能单独等同于噪声。100 ms 后段最差单项真实残差增加约 10.9%，所以不能宣称所有误差都改善。

额外使用 `synthetic(kind, factor, seed_offset=1000)` 的八段未参与筛选噪声实现复核：50/100 ms 真值误差平均下降 1.66%/1.96%，最差比值均小于 1，接受率不变。该复核只有随机噪声独立，运动场景仍相同；尚未实机验证。

复现：构建 `armor_noise_evaluation` 后运行 `python -m tests.tune_fixed_noise --horizon-ms 50 --output-dir tests/outputs/armor-noise-20261012`，再以 100 ms 输出到 `tests/outputs/armor-noise-20261012-100ms`。两份 ranking.csv 中的 candidate_181 为部署项；100 ms selected.json 是单次自动排名结果，并非最终部署项。独立噪声结果在 `tests/outputs/armor-noise-20261012-holdout`。下面保留旧版本调参记录作历史参考。

## 2026-09-30：历史参数

2026-09-30，装甲板 EKF 的所有观测统一使用：

```text
R = diag(0.0016, 0.0016, 0.16, 0.0576)
```

| 观测 | 方差 | 有效标准差 |
| --- | ---: | ---: |
| 目标方位角 | 0.0016 rad² | 0.04 rad，约 2.29° |
| 目标俯仰角 | 0.0016 rad² | 0.04 rad，约 2.29° |
| 距离 | 0.16 m² | 0.40 m |
| 装甲板朝向 | 0.0576 rad² | 0.24 rad，约 13.75° |

这些是与当前过程噪声、PnP 误差和模型近似配合使用的有效滤波参数，不是传感器实际噪声的统计标定。方位和俯仰较原参数获得更多权重；距离和板朝向的权重降低，减少它们对中心和角速度的扰动。距离绝对残差门限仍为 0.5 m。

## 数据与方法

真实数据使用 `tests/reference/recordings/camera_pose_raw_1.csv` 和 `tests/reference/recordings/pose_raw_2.csv`。前者约 11.4 秒、400 条观测，后者约 11.7 秒、415 条观测。`pose_raw_1.csv` 只有约 1.1 秒，因此不作为主要调参数据。真实数据没有外部位置/姿态真值。

另生成八段有真值的序列：定轴旋转、连续变速与停车、高速旋转、快速平移启停，各使用两档噪声。包含交替半径/高度、板号切换、双板观测、连续漏检和距离离群点。随机种子固定。

比较 319 组候选加原固定参数基线，共 320 组。过程噪声、初始化、NIS 门限、距离门限和多板联合更新保持相同。每段的前 70% 用于候选排序，后 30% 用于性能保护检查；后段也参与候选筛选，因此这不是完全独立的测试集。

评价包含三个部分：

1. 真实记录的未来观测残差。预测到 50 ms 后第一张可用图像的时间，本数据约为 66.7 ms；所有有效未来观测都参与统计，包括后续被门控拒绝的观测。
2. 仿真中恰好 50 ms 的中心位置和四块装甲板位置真值误差。用相邻真值状态插值得到 50 ms 真值。
3. 真实记录的中心位置帧间增量和角速度帧间增量 RMS，作为抖动指标，同时检查接受率。

各指标除以原固定参数的对应值后取平均，综合分数权重为未来残差 45%、仿真真值误差 35%、抖动 20%。接受率下降超过 2% 额外惩罚。筛除后段综合分数、单项残差或仿真误差显著退步的候选，避免仅追求平滑。具体保护门限见 `tune_fixed_noise.py`。

## 选定参数的结果

以下均相对于原固定参数 `diag(0.005, 0.005, 0.05, 0.05)`，数值为归一化指标的平均变化。

| 指标 | 前 70% | 后 30% |
| --- | ---: | ---: |
| 真实未来残差综合指标 | 降低 9.2% | 降低 2.0% |
| 仿真 50 ms 真值误差综合指标 | 降低 9.4% | 降低 7.5% |
| 中心/角速度抖动综合指标 | 降低 8.3% | 降低 8.8% |
| 真实观测接受数量 | 相同 | 相同 |

并非每个残差都下降。例如视频 2 后段的距离残差 RMS 从 0.07728 m 到 0.07765 m，板朝向残差从 0.23776 rad 到 0.24393 rad，俯仰残差从 0.001383 rad 到 0.001453 rad；方位残差从 0.01725 rad 降至 0.01343 rad，中心帧间增量 RMS 从 0.01710 m 降至 0.01476 m。这组参数用于在预测一致性、运动响应和抖动之间取折中。

完整逐序列统计在 `outputs/fixed_noise_tuning_final/measurements.csv`，候选排名在 `ranking.csv`，选定项为 `selected.json` 中的 `candidate_215`。真实记录的残差改善不能直接解释成绝对定位精度提升，结论只覆盖这些记录和仿真场景。

## 复现

在仓库根目录执行：

```powershell
cmake --build tests/build --config Release --target armor_noise_evaluation
.\.venv\Scripts\python.exe -B -m tests.tune_fixed_noise --output-dir tests/outputs/fixed_noise_tuning_final
```

测试构建需启用 `BUILD_TESTING`。评估程序只在显式构建该目标时编译，不加入常规测试。

运行正式预测时，在 `src/Armor.cpp` 选择 `PREDICTOR_ARMOR` 及视频路径，重新编译：

```powershell
cmake --build build --config Release --target Armor
.\Armor.exe
```
